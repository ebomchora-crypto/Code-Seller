# Local IDE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Executar nesta sessão, sem delegação, conforme autorização do usuário.

**Goal:** Expandir a IDE local com workspaces reais, terminal, Git e ferramentas de edição.

**Architecture:** Preservar React/Monaco/Zustand. API Node gerencia arquivos e processos separados. WebSocket conecta xterm a um PTY com confiança explícita por projeto.

**Tech Stack:** Node 22.12+, React 18, Monaco 0.57, Vite 7, node-pty, ws, xterm.

**Spec:** `docs/superpowers/specs/2026-10-09-local-ide-design.md`

## Global Constraints
- Sem Supabase, sem publicação automática e sem compatibilidade VSIX prometida.
- Somente `.code-makers/workspaces/<id>` para operações da IDE.
- Terminal exige confiança; não passar variáveis AI_* ou VITE_*.
- Checkpoints antes de substituição global, exclusão ou alterações externas.

## Verificação da entrega

- Terminal PTY isolado em processo próprio para evitar handles pendentes no Windows.
- Templates React novos compilam com Vite real; modelos anteriores preservados.
- Importação de pasta copia arquivos de texto e não modifica a origem.
- Editor dividido e dois terminais implementados.
- npm test: testes Node e Vitest; npm run build aprovado; npm audit sem vulnerabilidades.
- HTTP da IDE e API verificados em 127.0.0.1:5173. Navegador de automação indisponível; modelo de IA não configurado.

- Verificação final: 13 testes Node + 14 testes Vitest aprovados. Vite permaneceu ativo durante a suíte após ignorar workspaces e fixtures no monitoramento. Proxy WebSocket validado (403 para sessão inválida).
